# 第一课预习：从 MySQL 命令行到第一个 PR

跟着做完，你会得到：

- 一个能跑的 MySQL 8.0；
- 一张有 5 行数据的练习表；
- 会在 `mysql>` 里写增、改、删、批量增和条件查询；
- 一个通过自动评测的 Pull Request。

预计 60–75 分钟。所有 SQL 都在 MySQL 命令行里执行。卡住了先看 [常见错误](#6-常见错误)。

## 1. 安装 MySQL 8.0

这一节只给检查清单，不展开安装细节。

1. 打开 MySQL 官方下载页，下载 **MySQL Installer for Windows**。
2. 安装类型选 **Server only** 即可。
3. 配置时注意三件事：
   - 端口用默认的 `3306`；
   - 设置并记住 `root` 密码；
   - 勾选把 MySQL 注册为 Windows 服务。
4. 安装完成后记住 root 密码，下一步打开命令行。

> 已经装过 MySQL 8.0 的同学跳过这一节。

## 2. 打开 MySQL 命令行

### 2.1 先试 `mysql` 命令

打开 PowerShell 或 Windows Terminal，输入：

```powershell
mysql -u root -p
```

回车后输入安装 MySQL 时设置的 root 密码。

看到下面这个提示符，就说明登录成功：

```text
mysql>
```

再执行：

```sql
SELECT VERSION();
```

执行结果：

```text
+-----------+
| VERSION() |
+-----------+
| 8.0.44    |
+-----------+
1 row in set (0.00 sec)
```

看到 `8.0.x` 就说明连上了。你的版本号可能不是 `8.0.44`，只要以 `8.0` 开头就可以。

### 2.2 如果提示找不到 `mysql`

如果 Windows 提示：

```text
'mysql' 不是内部或外部命令，也不是可运行的程序
```

说明 `mysql.exe` 不在 PATH 里。两种办法：

1. **用开始菜单（推荐）**：开始菜单 → **MySQL 8.0 Command Line Client** → 输入 root 密码。
2. **配 PATH**：找到 MySQL 安装目录下的 `bin` 文件夹，把完整路径加到系统环境变量 `Path`，然后重新打开终端。
   - 复制 `bin` 文件夹的完整路径；
   - 此电脑 → 右键“属性” → 高级系统设置 → 环境变量；
   - 在“系统变量”里选中 `Path` → 编辑 → 新建 → 粘贴路径 → 确定；
   - 关闭并重新打开 PowerShell，再试 `mysql -u root -p`。

注意：MySQL 不一定装在 C 盘，不要照抄别人的 `C:\Program Files\...`。去开始菜单找，或者在自己的安装目录下找 `bin`。

### 2.3 先认识提示符

| 看到 | 含义 | 怎么办 |
| --- | --- | --- |
| `mysql>` | 可以输入 | 输入 SQL，末尾加 `;` 执行 |
| `->` | 语句还没结束 | 继续输入，或补 `;`；不想执行就输入 `\c` |
| `'>` | 单引号没闭合 | 补 `'`，或输入 `\c` 取消 |
| `">` | 双引号没闭合 | 补 `"`，或输入 `\c` 取消 |

记住三件事：

- **每条 SQL 以 `;` 结尾才会执行**；
- 字符串用英文单引号 `'张三'`，不要用中文引号 `‘张三’`；
- `\c` 取消当前没写完的语句，`\q` 或 `exit` 退出。

### 2.4 复制和粘贴

- Windows Terminal：`Ctrl+Shift+V`
- PowerShell：`Ctrl+V`
- 旧版 cmd：右键粘贴

可以一次粘贴多条 SQL，MySQL 会在每个 `;` 处执行。如果粘贴后看到 `->`，说明还差一个分号。

## 5. 条件查询

打开 `preview/05_select.sql`，一条一条执行。

```sql
-- 全部
SELECT id, name, score FROM members;

-- 比较
SELECT id, name, score FROM members WHERE score >= 85;

-- 字符串
SELECT id, name, major FROM members WHERE major = '计算机';

-- 模糊
SELECT id, name FROM members WHERE name LIKE '张%';

-- 范围
SELECT id, name, score FROM members WHERE score BETWEEN 80 AND 90;

-- 多选
SELECT id, name, major FROM members WHERE major IN ('计算机', '数学');

-- 组合
SELECT id, name, score FROM members
WHERE major = '计算机' AND score >= 85;

-- 排序 + 截断
SELECT id, name, score FROM members
ORDER BY score DESC, name ASC
LIMIT 3;

-- 计数
SELECT COUNT(*) AS cnt FROM members;

-- 分组
SELECT major, COUNT(*) AS cnt FROM members GROUP BY major;
```

练习方法：每条先照抄跑通，然后改一个条件再跑。

- 把 `>= 85` 改成 `>= 90`；
- 把 `'计算机'` 改成 `'数学'`；
- 把 `LIMIT 3` 改成 `LIMIT 2`；
- 把 `'张%'` 改成 `'%三'`。

## 6. 常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `mysql` 不是内部或外部命令 | 没配 PATH | 用开始菜单的 MySQL 8.0 Command Line Client，或把 `bin` 加进 PATH |
| `Access denied for user 'root'` | 密码错 | 重新执行 `mysql -u root -p` |
| `No database selected` | 没选库 | `USE preview;` |
| `Unknown database 'preview'` | 库没建 | `CREATE DATABASE IF NOT EXISTS preview CHARACTER SET utf8mb4;` |
| `Table 'preview.members' doesn't exist` | 表没建 | 先执行 `init.sql` |
| `ERROR 1064` | 语法错 | 检查中文引号、逗号、分号 |
| `ERROR 1050 Table 'members' already exists` | 表已存在 | 先 `DROP TABLE IF EXISTS members;` 再建 |
| `->` | 语句没结束 | 补 `;`，或输入 `\c` |
| 查询结果多出很多重复行 | 演示脚本重复执行了 | 重跑 `init.sql` |
| 所有人的分数都被改了 | `UPDATE` 忘了写 `WHERE` | 重跑 `init.sql`，重新来 |
| 整张表空了 | `DELETE` 忘了写 `WHERE` | 重跑 `init.sql`，重新来 |

三条保命习惯：

1. `UPDATE` / `DELETE` 之前，先用同样的 `WHERE` 跑一次 `SELECT`。
2. `UPDATE` / `DELETE` 必须带 `WHERE`。
3. 改坏了就重跑 `init.sql`，不要手工修数据。

## 10. 常见问题

### Q1：`autograde` 一直 Pending 怎么办？

第一次向仓库提交 PR，GitHub 需要维护者批准 workflow。等老师点一下即可，不用重复提交。

### Q2：`autograde` 红了，但不知道错在哪？

点 check 旁边的 `Details`，看 `Summary` 里的表格。每一项都会写期望值和实际值。

### Q3：我本地跑出来是对的，为什么评测不对？

评测会重置数据库，并使用另一份数据跑查询。检查：

- 查询里有没有写死姓名或分数；
- 有没有漏 `ORDER BY`；
- 列名、列顺序是否和题目一致；
- 有没有多写 `SELECT *`；
- 文件里有没有混进 `mysql>` 或 `->` 提示符。

### Q4：提示 `mysql` 不是内部或外部命令怎么办？

用开始菜单里的 **MySQL 8.0 Command Line Client**，或者找到 MySQL 安装目录下的 `bin`，把它加进系统环境变量 `Path`。MySQL 不一定装在 C 盘，不要照抄路径。

### Q5：MySQL 装的是 5.7，可以吗？

最好装 8.0。课程里的函数索引、`utf8mb4` 默认排序规则等都以 8.0 为准。

### Q6：可以只交 SQL，不写 README 吗？

不可以。README 占 10 分，也用来确认 GitHub 用户名。

### Q7：可以改 `preview/init.sql` 方便自己练习吗？

本地可以，但**不要提交到 PR**。PR 里只允许改 `submissions/<你的 GitHub 用户名>/hw01/` 下的文件。

### Q8：怎么退出 MySQL 命令行？

输入 `\q` 或 `exit`。
